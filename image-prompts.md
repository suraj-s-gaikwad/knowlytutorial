# Knowly — Home page image prompts

32 images — **every slot uses its own unique image, nothing is repeated.** Generate each one (ChatGPT / Midjourney / Gemini etc.), save it with the **exact filename** below into `assets/images/`, and refresh the page. Until a file exists, the page keeps showing the current stock photo, so you can add them one by one.

## How to save

- Format: **.jpg**, quality ~80% (compress at https://squoosh.app or tinyjpg.com — keep each file under ~300 KB).
- Export at least the **"Save at" width** listed (2× the display size, so it stays sharp on retina screens).
- Portrait = 4:5 or 2:3 · Landscape = 3:2 or 16:9 · Square = 1:1.
- Don't upscale tiny images — regenerate instead.

## Style block (paste at the end of EVERY prompt)

> Photorealistic editorial photography, natural soft daylight, warm neutral tones with subtle sage-green accents, clean modern premium learning space, shallow depth of field, 35mm lens, sharp focus on subject, realistic hands and faces, candid not posed, high detail, no text, no logos, no watermarks, no brand names.

Students should be diverse (Indian and international), aged 10–18, in smart-casual clothes (no school uniforms with crests).
